## 1. 结论摘要

**澜起科技 2026 上半年的真实图景是"一家优秀的公司在做正确的事，但市场用错误的数字在给它定价"。**

三句话：

1. **报表利润被一次性收益显著抬高。** 2026H1 归母净利 19.97 亿元、同比 +72.3%，但扣非归母仅 13.22 亿元、**同比 +21.2%**。差额 6.75 亿元非经常性损益（占归母净利 34%），其中 6.87 亿元是金融资产公允价值变动及处置收益——主要来自向 Marvell 出售 XConn 13.075% 股权的交易。**公司自己的核心业务增速是 21%，不是 72%。**
2. **但核心业务的成色在变好，不是在变差。** 互连类芯片毛利率升至 69.3%（同比 +4.95pp），毛利润 21.79 亿元（+36.9%），营业利润同比 +74.5%。Q2 单季毛利率从 69.8% 掉到 61.8% 是**产品结构（低毛利津逮产品季度间从 0.42 亿跳到 1.78 亿）造成的，不是定价压力**。这一点很关键——它把"毛利率恶化"这个看起来最吓人的信号排除掉了。
3. **估值层面，这只股票在扣非口径下是 110 倍 TTM，不是市场以为的 60–80 倍。** EV 2,338.9 亿元 / TTM 扣非归母 22.53 亿元 = **103.8x**。反推需要未来十年 FCF 复合增长约 **30–34%**，而公司 2016–2025 实际交付的 FCF CAGR 是 **18.5%**、营收 CAGR 是 **23.0%**。

**结论：这是一家护城河真实、资产负债表极强（净现金 133.7 亿元、资产负债率 7.5%）、产品代际领先的公司；但当前价格要求它做到自己历史上从未做到过的事。`watch_only`。**

### 2.3 另一个被忽略的利润拖累项：汇兑损失

公司明确披露：2026H1 **汇兑损失 1.74 亿元**（2025H1 仅 0.07 亿元），原因是人民币对美元升值，而公司持有大额外币资产——**主要是 H 股募资款**。FY2025 汇兑损失为 0.4075 亿元。

这条有双重含义：
- 短期：它压低了 2026H1 利润 1.67 亿元（同比维度），是"扣非只有 +21%"的部分原因，属于**非经营性、可逆**；
- 结构性：H 股募资带来的人民币升值敞口会**持续存在**，只要人民币处于升值通道，这就是一项经常性的、与主业无关的损益波动源。**这是募资的隐性成本，市场普遍没有定价。**

   - 行为救济（强制定价约束）会永久压低毛利率
   - 客户（三星/SK 海力士/美光）为了合规会主动分散供应，削弱澜起的定价权
   - 我的反推 DCF 中「30% 十年 FCF 复合增长」的起点（2026H1 年化 FCF 21.46 亿元）就建立在一个可能被修正的毛利率上

**这是一个"无主"的公司**：管理层（杨崇和仍任董事长兼 CEO）实际掌控经营，但 5% 以上股东只有 WLT+融迎合计约 5.8%。**好处**是管理层稳定、决策长期化；**风险**是没有一个股东有足够动力和权力去约束或更换管理层。

### 2.9 资本回报与股东行为：混合信号

**正面：**

- 连续 8 年现金分红（2020–2026），从未送股/拆股。

**负面：**
- **大股东减持**：2026-09-25 WLT Partners 计划减持不超过 2,330,000 股（0.19%），窗口 2026-11-02 至 2027-02-01。此前 2026-05-28 已通过询价转让减持 12,228,000 股（1.00%），价格 250.08 元；更早 上海融迎 减持 11,451,451 股（0.94%），价格区间 112.79–155.52 元。

- **分红率 12.10% 对一家净现金 133.7 亿元、资本开支仅 2.55 亿元/半年的公司来说偏低。** 大量现金以结构性存款和理财产品形式存在（2026H1 投资收益中含结构性存款收益），而非返还股东。

### 2.10 交易结构提示：XConn 出售的对价形式

公司向 Marvell 出售 XConn 13.075% 股权，预计对价 **5,800–6,500 万美元**（初始成本约 897 万美元，溢价 152%–182%）。**对价支付方式：60% 现金，40% 以 Marvell 股票支付，换股价 88.3554 美元/股。**

## 4. 判断层（含置信度与反转条件）

### J1 — 2026H1 的 +72.3% 严重高估了核心业务动量
- `judgment_confidence`: **高**
- 依据：P05–P08。扣非 +21.2%；非经常性损益占归母净利 34%（上年同期 5.9%）；剔除股份支付后扣非 +19.0%。
- **反面证据（必须承认）**：营业利润同比 +74.5%，毛利润 +36.9%，互连类毛利率 +4.95pp —— 经营层面确实在加速。所以准确表述是"**利润质量高的部分增长 21%，报表增长 72%**"，而不是"增长是假的"。
- `reversal_condition`: 若 2026Q3/Q4 扣非归母同比回到 40% 以上，说明核心业务真正在加速，本判断需要上修。

### J2 — Q2 毛利率环比大幅下滑是产品结构，不是定价压力
- `judgment_confidence`: **高**
- 依据：P11、P12。津逮单季收入 0.42 → 1.78 亿元；互连类毛利率 Q2 为 67.4%（同比 +3.2pp）；津逮毛利率仅 9.7%、占毛利 1.0%。
- `reversal_condition`: 若 2026Q3 互连类芯片本身毛利率（而非综合毛利率）跌破 65%，则本判断被推翻，需要重新评估竞争格局。

### J3 — 韩国卡特尔调查是当前最重要的、且性质被首版报告低估的风险
- `judgment_confidence`: **中高**
- 依据：P17、P17b、P17c、P17d、P17e。
- **首版报告把这件事写小了。** 公司公告只说自家办公室被查、用「潜在的违反反垄断相关法规」这种中性措辞；而韩联社与 Seoul Economic Daily 显示，**澜起、Renesas、Rambus 三家 MIC 全球供应商在同一天被同一个检察部门以同一罪名（违反《公平交易法》的价格串通）搜查**，并扣押了部分公司人员的手机。这不是一家公司的合规瑕疵。
- **为什么这比一般调查严重**：内存接口芯片全球只有三家，CR3 > 90%，澜起以约 36.8% 份额居首。这种结构本身就是卡特尔调查的典型对象。若串通指控成立，受威胁的是**69.3% 互连类毛利率的来源本身** —— 通过行为救济（强制定价约束）和**客户为合规而主动分散供应**（三星、SK 海力士、美光是全球 DRAM 的全部买家）。这是对估值分子的攻击，不是分母。
- **一个此前没被考虑的对立假设**：三家寡头在需求高度波动的行业里长期维持高且逐年抬升的毛利率、且在 2023 年营收 -37.8% 的低谷也不打价格战 —— 我原先把全部归因于技术壁垒。**串通假设为这个现象提供了竞争性解释。** 即使最终不成立，它也说明"高毛利 = 护城河"这一步推理缺少排他性。
- **必须同行的反面**：这仍是「혐의」（嫌疑），无人被起诉；韩国反垄断案件通常以 KFTC 罚款结案，刑事直送检察机关相对少见；即使最坏情况的罚款也不构成生存威胁（净现金 133.7 亿元）。**真正的伤害通道是行为救济与客户分散供应，不是罚款金额。**
- **这仍是 `irreducible_uncertainty`，但封顶更硬**：公司说无法预测时间和结果。现在至少能说清风险的性质与量级，但**在结果明朗前，任何基于当前毛利率的长期 DCF 都缺少可靠起点**。
- `reversal_condition`: （a）结案且不予起诉 → 毛利率来源的疑虑解除，可上修；（b）正式起诉或行为救济 → 需要把互连类毛利率假设整体下移，重做估值。

### J4 — 资产负债表是本次分析中最被低估的优点
- `judgment_confidence`: **高**
- 依据：现金 151.10 亿元、总负债 17.40 亿元、净现金 133.69 亿元、资产负债率 7.51%、流动比率 13.58。
- 净现金占市值 **5.4%**，且 EV/扣非 103.8x 已经扣除了这笔现金。
- **含义**：公司在任何行业下行中都不会死，并且有能力做一次改变格局的并购或大额技术投入。这是 2021–2023 下行期不具备的条件（当时权益仅 ~99 亿元、无 H 股平台）。
- `reversal_condition`: 若公司把这笔钱投入一项高溢价、低协同的并购，则本判断从"优点"转为"资本配置风险"。

### J5 — 营运资本恶化是真实的，但被其他信号部分抵消
- `judgment_confidence`: **中**
- 依据：G01、G02、G03。应收同比 +149%、存货周转从 3.30x 降到 1.22x（半年口径）、净利现金含量从 119.8% 降到 66.5%。
- **抵消证据**：经营现金流绝对额 13.28 亿元、同比 +25.4%（与收入 +26.7% 基本同步）；公司自称"经营现金流表现稳健，盈利转化能力良好"。**
- **我倾向的解释**：备货 + 客户结构变化。2026H1 收入 +26.7% 而应收 +149%，更可能是**账期结构变化或下半年集中确认**，而非收入质量问题。但**数据不足以区分良性与恶性**。
- `reversal_condition`: 2026Q3 报告若应收周转回到 8x 以上、存货周转回到 2.5x 以上，本判断解除；若继续恶化，则 J1 的"核心增长 21%"也要下修。

### J6 — 无控股股东 + 高被动持股，放大了股价与治理的双重脆弱性
- `judgment_confidence`: **中**
- 依据：P24。无实际控制人；前十大股东含 5 只指数 ETF；陆股通（香港中央结算）11.93%。
- **含义**：（a）指数调仓、ETF 申赎会带来与基本面无关的股价冲击；（b）北向资金流动会显著影响定价（已有报道显示 2026-06-30 至 07-23 北向持股从 1.458 亿股降至 1.395 亿股）；（c）治理上缺乏单一责任主体。
- `reversal_condition`: 若出现战略投资者大比例入股或管理层大额增持，本判断改善。

## 5. 我可能错在哪（反面证据）

1. **我可能低估了 MRDIMM/MCRDIMM 的爆发力。** 单条 MRDIMM 需要 1×MRCD + 10×MDB，单位价值量远高于普通 RDIMM 的 1×RCD。若 2027–2028 年 MRDIMM 大规模上量，30% 的 FCF 复合增长并非天方夜谭。**我的分析在这一点上证据薄弱**：公司自己的口径是"MRDIMM 仍处于第二子代规模试产阶段，行业预计还需 2–3 年才会快速上量"。这是管理层自己给的谨慎表述，我倾向于采信，但它也意味着**爆发的时间点不在 2026–2027，而在 2028+**——对估值折现是负面的。
2. **反推 DCF 对折现率极度敏感。** 我用 10%。若用 8.5%（更低的股权风险溢价），所需增速从约 30% 降到约 25–26%，结论会明显温和。**折现率的选择决定了结论强度，而这是一个判断而非事实。**
3. **汇兑损失 1.74 亿元是非经营性的。** 如果把它加回，2026H1 扣非会更高。我选择不加回，因为人民币升值敞口是 H 股募资带来的结构性后果，会持续存在——但这本身是一个可争议的判断。
4. **市场可能已经 price in 了扣非增速。** 70.2x 的 2026E PE 建立在一致预期 35.22 亿元上，而公司 2026H1 已做 19.97 亿元。若 H2 只做 15 亿元（低于 H1），全年就达不到一致预期——**这意味着一致预期本身可能面临下修风险**，而股价可能已经在反映这一点（近 3 月 -35.9%）。
5. **我的"反垄断调查是主因"仍是推理，不是事实。** 价格峰值（7/1，332.90）领先搜查日（7/15）10 个交易日，同期板块也在跌。时间吻合度很高，但不能排除这是一次板块级估值消化而调查只是加速剂。
6. **⚠️ 最重要的一条：我发现"三家同时被查"之后，并没有因此看多。** 直觉上「不是针对澜起一家」像是利好，但逻辑不对称 —— 如果串通指控成立，**超额利润的来源本身**就被否定了，那是对估值分子的攻击，不是分母。同时市场已经用 -30% 定价了这个事件（搜查日到披露日两个交易日跌了 28%），所以这更可能是一次**已被部分定价的风险**，而不是一个可交易的错价。我不认为这条信息构成买单理由。
7. **数据源单一性已部分缓解，但仍不完整。** 本次会话的 web_search 在报告完成后被修复，因此 J3 已用韩联社 / Seoul Economic Daily 一手源补强。但**行业需求侧数据（服务器 DRAM 供需、MRDIMM attach rate、DDR5 渗透率）仍然没有独立来源**，我的相关表述依旧只基于公司自己的公告与一个 TrendForce 标题（正文未取到）。

## 8. 研究动作与边界

本报告为 `watch_only` 级别产出。**不构成投资建议，不含买卖、加减仓、目标价或收益承诺。**

**在韩国调查结果明朗之前，本对象的 readiness 不应升级到 `actionable_with_caveats`。**

**下一步最有价值的四个动作（按增量信息排序）：**

1. **建立韩国反垄断调查的追踪项**：韩国公平交易委员会（KFTC）与首尔中央地检的公开进展、任何同行业（Rambus/Renesas）是否被同步调查、公司后续公告。**这是唯一能实质改变结论的变量。**
